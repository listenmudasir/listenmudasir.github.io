# listenmudasir.github.io

Personal academic homepage of Mudasir Hussain Bhat, served by GitHub Pages.

Plain HTML + CSS, no build step: edit `index.html`, commit, push — the site updates in about a minute.

## Common edits

- **Photo:** add a portrait (about 4:5, at least 600×750) at `images/profile.jpg`. Until then the page shows initials.
- **Paper figures** live in `images/pubs/` (≈1400 px wide JPG).
- **News:** add a new `<li>` at the top of the `News` list.
- **Publication:** copy one `<article class="pub">` block, then change the title, venue, links, thumbnail and BibTeX.
  Replace the illustrative SVG thumbnail with a real teaser figure (`<img src="images/xxx.png">`) when you have one.
- **Google Scholar / CV:** uncomment the placeholders in the profile links list. Remove phone numbers from any CV PDF before publishing it.
